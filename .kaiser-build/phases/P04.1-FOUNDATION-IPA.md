## CAPABILITIES

### CAP-001: foundation.artifact_detect

**Contract**:
```yaml
id: foundation.artifact_detect
version: 1.0.0
domain: foundation
name: Artifact Detection

inputs:
  required:
    - name: artifact_path
      type: path
      
supported_artifacts:
  input:
    - "*"  # Any file type
  output:
    - type: artifact_type
      values: [ipa, app_bundle, macho, framework, dylib, unknown]

adapters:
  required: [file_adapter]
  optional: []

output:
  success:
    artifacts: []
    metadata:
      artifact_type: string
      mime_type: string
      size_bytes: int
      is_valid: bool
      
errors:
  E001: "Cannot read artifact"
  E002: "Empty file"

tests:
  - fixture: valid_app.ipa
    expected: {artifact_type: ipa}
  - fixture: corrupt_app.bin
    expected: {artifact_type: unknown}
```

### CAP-003: ipa.unpack

**Contract**:
```yaml
id: ipa.unpack
version: 1.0.0
domain: foundation
name: IPA Unpacking

inputs:
  required:
    - name: artifact_path
      type: path
    - name: output_dir
      type: path
      
supported_artifacts:
  input:
    - type: ipa
  output:
    - type: extracted_payload
    - type: extraction_log

adapters:
  required: [unzip_adapter]
  optional: [sevenzip_adapter, python_zipfile_adapter]

fallback:
  levels:
    - unzip
    - 7z
    - python_zipfile

partial_success:
  trigger_on: [permission_denied, symlink_loop]
  do_not_trigger_on: [corrupt_archive, missing_executable]

output:
  success:
    artifacts:
      - path: "{output_dir}/Payload"
        type: directory
    metadata:
      files_extracted: int
      
  partial:
    artifacts:
      - path: "{output_dir}/Payload.partial"
        type: directory
    warnings:
      - code: W001
        message: "{count} files skipped"
```
