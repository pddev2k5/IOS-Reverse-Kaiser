# EP-04.4A: Component Model

**Date**: 2026-09-04
**Phase**: P04 - Capability Layer
**Subphase**: P04.4 - Component Inventory

## Summary

Introduced normalized application component model for P04.4.

## Model Entities

| Entity | Purpose |
|--------|---------|
| ComponentType | APPLICATION, FRAMEWORK, DYLIB, EXTENSION, BUNDLE |
| Classification | EMBEDDED, SYSTEM_EXTERNAL, UNKNOWN |
| DependencyState | RESOLVED_EMBEDDED, EXTERNAL_SYSTEM, UNRESOLVED, AMBIGUOUS |
| EdgeType | CONTAINS, LOADS, WEAK_LOADS, REEXPORTS |

## Component Hierarchy

```
BaseComponent (abstract)
├── AppComponent - Main .app bundle
├── FrameworkComponent - .framework bundles
├── DylibComponent - .dylib files
├── ExtensionComponent - .appex bundles
└── BundleComponent - Generic bundles
```

## Component Identity

- **component_id**: Deterministic ID based on SHA-256(name:artifact_id:bundle_path)
- **artifact_id**: SHA-256 of the artifact content
- **bundle_path**: Relative path within parent

## Dependency Model

- **Install names**: @rpath, @loader_path, @executable_path, absolute, system
- **States**: resolved_embedded, external_system, unresolved, ambiguous
- **Edge types**: LOADS, WEAK_LOADS, REEXPORTS
