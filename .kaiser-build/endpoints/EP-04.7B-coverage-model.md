# EP-04.7B: Coverage Model

**Date**: 2026-09-04
**Phase**: P04.7 - Reporting + Coverage
**Subphase**: EP-04.7B

## Summary

Created normalized coverage model for analysis coverage tracking.

## Core Entities

| Entity | Purpose |
|--------|---------|
| CoverageState | COVERED, PARTIAL, FAILED, NOT_APPLICABLE, NOT_ATTEMPTED, UNKNOWN |
| CoverageDimension | BINARY, OBJC_METADATA, CRYPTO, NETWORK, etc. |
| CoverageTarget | Target eligible for coverage |
| CoverageObservation | Observation about coverage for target/dimension |
| CoverageGap | Gap in coverage |
| CoverageSummary | Complete coverage summary |
| CoverageAudit | Full coverage audit |

## Coverage States

| State | Meaning |
|-------|---------|
| COVERED | Successfully analyzed |
| PARTIAL | Partially analyzed |
| FAILED | Attempted but unsuccessful |
| NOT_APPLICABLE | Not applicable for this target |
| NOT_ATTEMPTED | Eligible but not attempted |
| UNKNOWN | Unknown state |

## Key Design Decisions

1. **NOT_ATTEMPTED ≠ FAILED**
   - NOT_ATTEMPTED = eligible but not run
   - FAILED = attempted but unsuccessful
   - These are semantically different

2. **NOT_ATTEMPTED ≠ 100% Coverage**
   - Coverage rate excludes NOT_ATTEMPTED from denominator
   - 10 eligible, 8 analyzed, 2 not attempted → 80% coverage
   - NOT 100%

3. **execution_success ≠ coverage_complete**
   - execution_success = all attempted analyses succeeded
   - coverage_complete = all eligible targets were attempted

4. **Coverage denominator is explicit**
   - Always track eligible target count
   - Never calculate from only successful analyses
