## Key Design Decisions

### Evidence Strength Hierarchy
- STRING_HINT < REFERENCE < STRUCTURAL < CORRELATED < VERIFIED
- String "AES" alone → STRING_HINT, NOT VERIFIED

### Library/Framework Presence ≠ Usage
- Framework linked ≠ app uses it
- Security.framework linked ≠ custom crypto

### Algorithm = UNKNOWN without evidence
- Don't claim specific algorithm without proof
- "AES" in strings alone → UNKNOWN

### Indicator ≠ Verified Mechanism
- Jailbreak path string → INDICATOR
- Not confirmed jailbreak detection
- ptrace import → REFERENCE
- Not verified anti-debug

### Key Material = Conservative
- Do NOT expose raw keys
- Record evidence location only

### Binary Encryption ≠ Application Crypto
- LC_ENCRYPTION_INFO belongs to binary protection
- NOT evidence of AES/HMAC usage
