# EP-04.6D: Anti-Analysis Model

**Date**: 2026-09-04
**Phase**: P04.6 - Crypto + Anti-analysis
**Subphase**: EP-04.6D

## Summary

Created normalized anti-analysis model for mechanism detection.

## Model Entities

| Entity | Purpose |
|--------|---------|
| EvidenceStrength | STRING_HINT, REFERENCE, STRUCTURAL, CORRELATED, VERIFIED |
| AntiAnalysisCategory | DEBUGGER_DETECTION, JAILBREAK_INDICATOR, INTEGRITY_CHECK, etc. |
| IndicatorState | INDICATOR, REFERENCE, CORRELATED_CHECK, VERIFIED_MECHANISM |
| AntiAnalysisIndicator | Indicator of anti-analysis behavior |
| AntiAnalysisReference | Reference to anti-analysis symbol/API |
| AntiAnalysisEvidence | Individual evidence piece |
| AntiAnalysisFinding | Finding/correlation |

## Categories

| Category | Description |
|----------|-------------|
| DEBUGGER_DETECTION | Anti-debugger mechanisms |
| JAILBREAK_INDICATOR | Jailbreak detection |
| INTEGRITY_CHECK | Code integrity checks |
| ENVIRONMENT_CHECK | Environment detection |
| DYNAMIC_INSTRUMENTATION | Anti-instrumentation |
| ANTI_HOOKING | Anti-hooking measures |
| ANTI_TAMPER | Anti-tampering |
| OBFUSCATION | Obfuscation indicators |
| PACKING | Packing indicators |
| CODE_SIGNING | Code signing related |
| ENCRYPTION_STATE | Binary encryption |
| UNKNOWN | Unclassified |

## Indicator States

| State | Description |
|-------|-------------|
| INDICATOR | Raw indicator found |
| REFERENCE | Symbol/API reference |
| CORRELATED_CHECK | Correlated with function |
| VERIFIED_MECHANISM | Confirmed mechanism |

## Key Design Decisions

1. **Indicator ≠ Verified Mechanism**
   - Jailbreak path string → INDICATOR
   - Not confirmed jailbreak detection

2. **API Import = REFERENCE only**
   - ptrace import → REFERENCE
   - Not confirmed anti-debug

3. **Evidence Strength Hierarchy**
   - Same as crypto: STRING_HINT < REFERENCE < STRUCTURAL < CORRELATED < VERIFIED

4. **Be Conservative**
   - Single heuristic ≠ packed/obfuscated
   - Multiple weak signals may aggregate
