## Detection Sources

Framework detection uses multiple evidence sources:
- Binary strings
- ObjC metadata (classes, selectors)
- Swift metadata (types)

## Framework Indicators

| Framework | Indicators |
|-----------|------------|
| URLSession | NSURLSession, URLSession, NSMutableURLRequest |
| CFNetwork | CFNetwork, CFHTTP, CFFTP |
| Network.framework | NWConnection, NWEndpoint, NWBrowser |
| Alamofire | Alamofire, AFHTTPSessionManager, Session.request |
| AFNetworking | AFNetworking, AFSecurityPolicy |

## Presence Levels

| Level | Description |
|-------|-------------|
| EMBEDDED | Framework binary is present |
| USAGE_SUSPECTED | Multiple evidence indicators |
| USAGE_CONFIRMED | Strong evidence of usage |
| USAGE_UNKNOWN | Cannot determine |

## Key Invariant

Framework presence ≠ confirmed usage.
