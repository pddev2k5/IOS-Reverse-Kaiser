# EP-04.7F-04.7G: Report Renderers

**Date**: 2026-09-04
**Phase**: P04.7 - Reporting + Coverage
**Subphase**: EP-04.7F + EP-04.7G

## Summary

Implemented JSON and Markdown renderers for reports.

## JSON Renderer

Produces machine-readable output suitable for programmatic consumption.

Features:
- Deterministic output (sorted keys)
- Complete data preservation
- Custom serialization for dates and enums

## Markdown Renderer

Produces human-readable output for review.

Features:
- Table of contents
- Section organization
- Finding summaries
- Coverage gaps
- Error/warning sections

## Coverage Renderer

Dedicated renderer for coverage audits.

Features:
- JSON format for machine consumption
- Markdown format for human review
- Gap summaries
- Rate summaries

## Key Design Decisions

1. **Renderer separate from model**
   - Report model is normalized
   - Renderers handle output format

2. **Claim strength in output**
   - Markdown shows human-readable strength
   - JSON preserves enum values

3. **Sensitive data handling**
   - JSON renderer does not redact (programmatic use)
   - Markdown renderer should redact in human-readable contexts
