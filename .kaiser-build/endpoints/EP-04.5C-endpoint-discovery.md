## Evidence Strength for Endpoints

| Strength | Meaning |
|----------|---------|
| STRING_HINT | Found in strings only |
| REFERENCE | Referenced by code |
| STRUCTURAL | From parsing structures |
| CORRELATED | Correlated with other evidence |
| VERIFIED | Confirmed by analysis |

## HTTP Method Evidence

Method is UNKNOWN without evidence.

Evidence sources:
- Literal HTTP method near URL
- API call semantics
- Structured request metadata

## Key Invariants

1. URL in strings alone → STRING_HINT
2. STRING_HINT cannot become VERIFIED without evidence
3. Method = UNKNOWN without method evidence
4. Header producer = None/unresolved without evidence
5. Base URL and path can be separate candidates

## Deduplication

- Same endpoint in multiple forms → single candidate ID
- Multiple evidence refs preserved
- Multiple sources (strings, ObjC, Swift) aggregated
