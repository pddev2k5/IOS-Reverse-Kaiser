**Date**: 2026-09-04

## Summary

Created normalized report model for report generation.

## Core Entities

| Entity | Purpose |
|--------|---------|
| ReportSection | Sections like EXECUTIVE_SUMMARY, CRYPTO, COVERAGE |
| ClaimStrength | SUSPECTED, INFERRED, DETECTED, VERIFIED |
| FindingType | Types of findings |
| ReportFinding | A finding in the report |
| ReportSectionData | Data for a section |
| ReportMetadata | Report metadata |
| Report | Complete report |

## Claim Strength Mapping

| Evidence Level | Claim Strength |
|---------------|---------------|
| string_hint | SUSPECTED |
| reference | INFERRED |
| structural | DETECTED |
| correlated | DETECTED |
| verified | VERIFIED |

## Key Design Decisions

1. **Model separate from renderer**
   - Report model is normalized
   - Renderers produce output

2. **Evidence strength preserved**
   - STRING_HINT → SUSPECTED
   - Not promoted to DETECTED/VERIFIED

3. **Sensitive data handling**
   - Keys with "api_key", "token", "secret" redacted
   - Conservative approach

4. **Claim discipline**
   - SUSPECTED remains SUSPECTED
   - Never rewrite to higher strength
