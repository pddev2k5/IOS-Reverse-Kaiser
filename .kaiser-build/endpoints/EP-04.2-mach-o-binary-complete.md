## Adapter Strategy

| Adapter | Required | Platform | Fallback |
|---------|----------|----------|----------|
| mach_o_parser | Yes | All | None (pure Python) |
| otool | No | macOS | parser |
| nm | No | macOS | partial (no symbols if unavailable) |
| strings | No | All | Python fallback |

## Key Design Decisions

1. **Pure Python parser** - Works on all platforms without external dependencies
2. **Tool abstraction** - Adapters normalize tool-specific outputs
3. **Cross-endian support** - Parser handles both little and big endian Mach-O
4. **Fat binary limitation** - Full fat binary parsing requires macOS tools on little-endian hosts
